About
A performance and visual enhancement Fabric modpack for Minecraft
Java Edition 1.21.1, compatible with TLauncher, Official
Minecraft Launcher, Prism Launcher, MultiMC, SKLauncher,
ATLauncher, and other Fabric-compatible launchers.
> \[!NOTE\] Most installation problems are caused by incorrect setup.
> Please watch a Fabric installation tutorial before opening an issue.
> \[!IMPORTANT\] I analyzed **TLauncher v2.9371** using reverse
> engineering techniques and VirusTotal scans. My assessment applies
> only to **that specific version**.
