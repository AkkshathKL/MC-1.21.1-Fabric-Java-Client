# MC 1.21.1 Fabric Java Client

A performance and visual enhancement **Fabric modpack** for **Minecraft 1.21.1**, designed to work with **TLauncher**, **Official Minecraft Launcher**, **SKLauncher**, **ATLauncher**, and other launchers that support Fabric.

## About

This modpack has been carefully configured for Minecraft 1.21.1 and includes compatibility fixes for **TLSkin & Cape** users. It is intended to provide a smoother, more polished Minecraft experience while remaining easy to install.

## Installation

**Low End Devices (TLauncher Only)**: https://github.com/AkkshathKL/MC-1.21.1-Fabric-Java-Client/releases/tag/Low_End_Devices_Win11

**High End Devices (TLauncher Only)**: https://github.com/AkkshathKL/MC-1.21.1-Fabric-Java-Client/releases/tag/High_End_Devices_Win11

### Clean Installation (Recommended)

1. Download the latest release from the **Releases** section.

2. Extract the ZIP file using Windows Explorer, WinRAR, or 7-Zip.

3. Press **Windows + R**.

4. Type:

   ```text
   %appdata%
   ```

5. Press **Enter**.

6. Open the **.minecraft** folder.

7. Open the **versions** folder.

8. Copy the extracted **MC-1.21.1-Fabric-Java-Client** folder into:

   ```text
   %appdata%\.minecraft\versions
   ```

9. Launch your preferred launcher.

### TLauncher

1. Open TLauncher.
2. Refresh the version list if necessary.
3. Select **MC-1.21.1-Fabric-Java-Client**.
4. Click **Enter the Game**.

### Official Minecraft Launcher

1. Open Minecraft Launcher.
2. Go to **Installations**.
3. Create a new installation if needed.
4. Select the installed Fabric version.
5. Launch the game.

### SKLauncher / ATLauncher / Prism Launcher / MultiMC

1. Import or select the installed Minecraft version.
2. Ensure Fabric 1.21.1 is selected.
3. Launch the game.
